# 狗头军师桌面版（goutoujunshi-desktop）

把两个能力缝成一个程序：

- **狗头军师**：关系判断、分寸把握、可直接发送的话术（原技能在 `<你的用户目录>\.agents\skills\goutoujunshi`）。
- **进程聊天工具**：在 Windows 上读消息、发消息（原技能在 `<你的技能目录>\.dsh\skills\process-chat-tool`）。

本项目的产出是一个**桌面程序**（日常点着用）＋ 一个 **DSH 技能包**（在对话里直接用），
两者共用同一套档案与规则。

## 现在处于哪一步

**1.0.0：四条链路都通了。** 读消息、给建议、自动发送（含三个子档）、**关系体检**——
**仍然不发图片和表情包、群聊仍然只提醒不代发**。

最近这几版做了什么：

1. **0.3.x 换直连 + 修速度**：原来每次问军师都要起一个 DSH 子进程（光起进程就 1.87 秒）；
   换直连后省掉这段，并且**边生成边显示**。又发现智谱 `glm-5.3` 系列默认"深度思考"
   （先想一万八千字、首字 136 秒），改成显式 `reasoning_effort: low` + 两段式后，
   **首选 1.36 秒到手**。
2. **0.4.x 关系背景与档位**：「资料」页能填（关系 / 称呼 / 雷区 / 近期事件），
   写进那份画像文件、随画像一起送给模型；每个会话有标签与「军师参与」开关；
   档位与静默退出收进设置。
3. **0.5~0.7 全自动**：授权状态机、发送链路、停手条件、演练模式，
   单次 / 常驻 / 限时三个子档全部上线（单次档已真机发过）；聊天记录每秒自动刷新。
4. **1.0.0 关系体检**（右侧「关系」页）：把整段聊天在本地算成客观数字
   （谁更主动、谁回得快、最近是热还是冷、最长断聊几天…），再挑一份样本让军师
   按【现状】【投入】【好信号】【坏信号】【风险】【接下来】六块解读。
   **数字在前、解读在后**——模型那几句你可以不信，数字是自己算的。

界面：左边会话列表（搜索 / 未读红点 / 群标记），中间气泡聊天记录，右边军师建议
（【判断】【首选】【备选】【风险】四张卡片），外加复盘浏览、资料面板、设置窗口与系统托盘。

想看界面又不想开微信：`python -m goutou_chat --demo`（用假数据，界面上会标明「演示数据」）。

## 第一次用要先做一件事

打开程序 → 点右上角「**设置**」→ 粘一把 API key → 点「**测试连接**」（它会真发一个最小请求，
告诉你通不通、首字多少毫秒）。没填 key 也能用，只是走老的兜底通道，会慢一些。

key 存在 `关系档案\配置\secrets.json`，已写进 `.gitignore`，不会进版本库。

## 怎么跑

```powershell
Set-Location <项目根>\app

# 命令行：体检 / 列会话 / 读记录 / 问军师（只出字，不发）
python -m goutou_chat --health
python -m goutou_chat --sessions
python -m goutou_chat --read 联系人A --limit 20
python -m goutou_chat --advice 联系人A

# 界面
python -m goutou_chat                 # 真实数据（需要微信 + 读取后端在跑）
python -m goutou_chat --demo          # 假数据，只看界面效果

# 自测
python -m unittest discover -s tests -v

# 打包
pwsh -File .\build.ps1                # 单文件版 + 文件夹版
pwsh -File .\build.ps1 -Shortcut      # 顺手在桌面建快捷方式（会写到工作区之外，故需显式加）
```

工作目录请用 `<项目根>\app`，或设置 `GOUTOU_HOME` 指向项目根。

## 两个打包版本怎么选

| 版本 | 位置 | 启动到出窗口（本机实测） | 什么时候用 |
| --- | --- | --- | --- |
| 文件夹版 | `dist\goutou-chat-app\goutou-chat-app.exe` | **0.76 秒** | 日常（桌面快捷方式指向它） |
| 单文件版 | `dist\goutou-chat.exe` | 1.22 秒 | 想只拷一个文件走的时候 |

## 三条硬规矩

1. **发错人比晚回消息严重得多**：任何发送前都要核对面孔，且必须带上下文校验（过期就拒发）。
2. **群聊不给建议、永不进全自动**；钱、健康、出行、要本人拍板的事，程序不许替你承诺。
3. **永远不发图片和表情包**——那是本人亲手立的人机分界线。

## 打包后的程序怎么找数据

程序靠 `VERSION` 与 `关系档案` 两个目录定位项目根：放在 `app\dist\` 下时往上找就能找到。
如果把它单独拷到别的机器，请设环境变量 `GOUTOU_HOME` 指向数据根所在目录，
否则它会退到程序所在目录另建一份空的。
