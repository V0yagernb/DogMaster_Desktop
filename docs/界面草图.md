## 流式（0.3.0 起）

军师的输出不再"等全部想完再一次性显示"，而是**边收边填**：先出现【判断】，接着【首选】
那行一出现就能复制，剩下的【备选】【风险】继续往下长。状态栏同时写清这次是"直连"还是
"兜底通道"——回退时绝不让人以为它变快了。

## 流式与两段式（0.3.1 起）

点「让军师看一眼」之后发生的事，按时间顺序：

1. **0.0~1.4 秒**：状态栏写"军师正在想…"，模型若在思考，那一行会实时显示
   "军师正在想…（已 N 字）"+ 最近一段思考内容——**等待看得见**，不是白屏。
2. **约 1.4 秒**：【判断】【首选】先出现，【备选】【风险】两块写"正在补…"。
   **这时首选已经可以复制去发了。**
3. **约 8 秒**：【备选】【风险】流式填进来，状态栏报"直连：首字 X 秒，两段合计 Y 秒"。

如果直连不可用，会回退到兜底通道一次出全部，状态栏**写明"这次走的是兜底通道"**——
绝不让人以为它变快了。

**聊天区顶部多了两样**：

```
│ 联系人A  8 条记录            标签：[暧昧 ▼]  ☑ 军师参与   [刷新记录] │

│ 对象：联系人A                                            │
│ ┌ 授权范围 ──────────────────────────────────────┐   │
│ │ 子档：        [全自动·单次（发完即失效） ▼]     │   │
│ │ 没动作就收回： [30 分钟]                        │   │
│ │ ☑ 先演练：跑完整判定但不真的发（推荐先跑一次）  │   │
│ └────────────────────────────────────────────────┘   │
│ ┌ 不管怎么选，下面这些都不会变 ──────────────────┐   │
│ │ · 群聊永不进全自动（哪怕在这里开了也不发）      │   │
│ │ · 要发的话里出现钱/承诺/见面这类词，当场降级成草稿 │ │
│ │ · 每条消息进键盘之前，都会再过一次紧急制动      │   │
│ │ · 发出的每一条都写进复盘，并在托盘弹一次提醒    │   │
│ └────────────────────────────────────────────────┘   │
│ ┌ 确认 ──────────────────────────────────────────┐   │
│ │ ☑ 我知道它会替我把消息发出去，出事我认          │   │
│ │ [把「我知道」两个字打一遍                     ] │   │
│ └────────────────────────────────────────────────┘   │
│                                        [取消] [开启]  │
└──────────────────────────────────────────────────────┘
```

授权生效期间，主窗顶部会出现一条状态（不是藏起来的）：

```
⚠ 全自动生效：全自动·单次｜对象：联系人A｜还剩 27 分钟｜还能自动发 1 条｜演练中（不会真发）
                                                      [演练一次] [立即收回]
```

三条规矩：**默认演练**（不会真发，先看它本来会说什么）；**随时可收回**；
**程序退出时自动收回授权**（免得昨天开的授权今天还挂着）。

### 真发的四个入口（0.6.0）

授权生效后，状态条右侧这一排按钮：

| 按钮 | 做什么 | 会不会碰你的屏幕 |
| --- | --- | --- |
| **演练一次** | 读记录 → 拟稿 → 走完整判定，显示"本来会发这句" | 不会（连切会话都不做） |
| **试切一次** | 只做"切到这个会话"，把上游截的标题图给你核对 | **会**（把目标窗口提到前面） |
| **暂停盯人 / 继续盯人** | 停/开"他发来我就接"的自动检查 | 不会 |
| **立即收回** | 当场作废授权，回到建议档 | 不会 |

真发模式（授权对话框里把"先演练"的勾去掉）下，第一个按钮会变成「**立刻接一次**」——
手动跑一遍完整流程：拟稿 → 切会话 → 带着哈希发送。**第一次对某个人真发，就用这个**，
别开着自动盯人让它自己动手。

## 三个子档什么时候失效（0.7.0 起全部可用）

| 子档 | 一直自动回吗 | 什么时候失效 |
| --- | --- | --- |
| **单次** | 不，只发一条 | 发出任意一条就失效，立刻回到建议档 |
| **常驻** | 是，条数不限 | 你点「立即收回」/ 触发停手条件 / 「没动作就收回」到点（上限 = 静默时长 ×2） |
| **限时** | 是，条数不限 | 到你设的「授权时长」自动收回（默认 60 分钟），不管当时聊到哪 |

三档共用同一套闸门（授权 / 目标匹配 / 群聊 / 红线 / 制动 / 上下文指纹 / 停手条件），
差别只在"什么时候失效"——所以换子档不需要换代码，只是换一张授权。

**停手条件**（三档都生效）：对方连着冷淡 N 次、对方连着没什么实质内容、自动轮数到上限、
静默超时。命中任何一条就停，并在状态栏写清是哪一条。

## 关系体检页（1.0.0）

右侧多了一个「关系」页。选一个人 → 点「分析整段聊天」，它先把整段记录在**本地**算成数字，
再挑一份样本送去让军师解读：

```
[分析整段聊天]  看最近 [800] 条
统计 500 条（样本 200 条）｜直连｜首字 1.0 秒｜共 17.4 秒
┌────────┐┌──────────┐┌────────┐
│ 500    ││ 46%      ││ 57 天  │
│ 消息总数││ 我发的占比││ 时间跨度│
└────────┘└──────────┘└────────┘
┌────────┐┌──────────┐┌────────┐
│ 16 秒  ││ 我 8/对方 25││ 56 条 │
│ 对方回我││ 谁先开口  ││ 最近7天│
└────────┘└──────────┘└────────┘
┌【现状】…… 至少引用两个统计数字 ────────────────┐
┌【投入】谁更主动、谁回得更快、是不是失衡 ────────┐
┌【好信号】最多 3 条 ────────────────────────────┐
┌【坏信号】最多 3 条 ────────────────────────────┐
┌【风险】最可能出问题的地方 ──────────────────────┐
┌【接下来】2-3 条具体能做的事 ────────────────────┐
```

设计上的顺序是刻意的：**数字在前、解读在后**。模型那几句你可以不信，数字是本地算的，赖不掉。

样本是"最近的 120 条 + 最早的 30 条 + 中间均匀抽 50 条"——只给最近的不行，
那样分不清「一直这样」还是「最近变了」。

## 每个控件的规矩

| 控件 | 行为 | 依据 |
| --- | --- | --- |
| 档位（在设置里） | 全自动三项**置灰**；当前档位在状态栏左下显示 | 不拿没实现的能力骗人（ADR-0002） |
| 静默退出分钟（在设置里） | 改完点保存才写盘，默认 15 | ADR-0014 |
| 紧急制动（大红） | 永远可点；按下后停一切自动动作、作废未发内容、并明确告知"已进键盘的那条撤不回" | ADR-0013 |
| 解除制动 | 必须手动解除，程序不自动恢复 | 制动不能被程序自己撤销 |
| 体检条 | 逐项打勾，鼠标悬停看完整报告，「明细」就地展开 | "不做假绿" |
| 会话列表 | 群会话带 `［群］` 前缀、未读标红点数字、有未读的排最前、可搜名字与最后一句 | 一眼看出哪些永不进全自动 |
| 聊天记录 | 气泡：我方靠右绿底、对方靠左白底；超过 5 分钟插一条时间；非文本显示 `[图片]` 之类的占位。**每秒自动刷新**（真变了才重载，翻历史时不会被弹回底部）；「刷新记录」按钮留着做强制刷新 | 不假装有内容 |
| 生成建议 | 后台起 DSH headless（约 3 秒），结果拆成四张卡片 | ADR-0007 |
| 复制首选话术 | 只复制 `【首选】` 那一行 | 建议档的出口是本人自己发 |
| 群聊提示 | 选中群会话时军师按钮**灰掉**并写明"群聊不给建议" | ADR-0004 / ADR-0020 |
| 状态栏 | 直连写"首字 X 秒 / 共 Y 秒"；兜底写"这次走的是兜底通道" | 通道必须如实说（ADR-0019） |
| 系统托盘 | 点关闭收进托盘（可在配置里改成直接退出）；托盘右键有紧急制动 | 盯消息的人不该被误关 |
| `--demo` | 用假数据填满界面，标题栏与顶栏都标明"演示数据" | 不做假绿 |

## 演示模式（给验收用）

微信和读取后端都没起的时候，界面是空的，看不出效果。所以有一个演示模式：

```powershell
Set-Location F:\goutoujunshi\app
python -m goutou_chat --demo        # 界面上会标明「演示数据（不是真实聊天记录）」
```

它的数据在 `app\goutou_chat\ui\demo.py`，是固定的一份假聊天；演示模式下**不碰** wda
（读取后端）与 pct（发送零件），也不写任何真实复盘。

要出截图（不上屏，不打扰正在用电脑的人）：

```powershell
python tools\ui_preview.py --out F:\goutoujunshi\_preview
```

注意它默认用 `windows` 平台插件 + `WA_DontShowOnScreen`：本机的 Qt `offscreen` 插件
字体库是空的（实测 0 个字体），用它截出来的图一个字都没有。
