## 模块职责

| 文件 | 职责 | 关键约束 |
| --- | --- | --- |
| `config.py` | 路径与配置 | 数据只住 `关系档案\`；军师知识只引用；`project_home()` 要认得出打包后的 exe |
| `rules.py` | 档位、红线、停手条件、授权状态机 | `may_auto_send()` 与 `auto_send_decision()` 是自动发送的**唯一**入口 |
| `sender.py` | 自动发送编排（判定 → 制动 → 演练/真发 → 记账） | 进键盘前必须再过一次制动；exit 4 绝不重发 |
| `autopilot.py` | 自动驾驶（盯新消息 → 拟稿 → 切会话 → 发送） | 演练不碰屏幕；真发先切会话拿哈希再发 |
| `analysis.py` | 关系体检：客观统计 + 样本抽样 + 任务书 + 结果解析 | 统计是纯函数、不联网；模型只拿到统计与一份抽样 |
| `wda.py` | 读取后端 HTTP 客户端 | 只读；封死会把数据外传的两个端点 |
| `pct.py` | 上游零件调用 | 只调冻结副本；exit 4 = 拒发（不许当错误吞掉） |
| `health.py` | 开机体检 | 逐项真验，不做假绿 |
| `llm.py` | 直连通道（OpenAI 兼容 + SSE 流式） | 拿不到 key / 连不上就抛 `LlmUnavailable`，绝不假装成功 |
| `advisor.py` | 通道调度：直连优先、兜底在后 | 回退必须说出来（状态栏写"这次是兜底"） |
| `brain.py` | 任务书拼装、输出解析、DSH 兜底通道 | 走 DSH 时不拼 `--model`（headless 不认）；`parse_advice()` 是纯函数 |
| `archive.py` | 档案读写 | 独占写入；记忆库走军师原脚本 + 换存储位置 |
| `brake.py` | 紧急制动 + 全局热键 | ctypes 调 Win32，无新依赖；`check()` 抛错不许吞 |
| `ui\theme.py` | 配色与全局样式表 | 界面代码里**不许**再写死颜色 |
| `ui\main_window.py` | 主窗装配、托盘、后台任务 | 全自动档置灰；制动永远可点；退出必须 `shutdown()` |
| `ui\settings_dialog.py` | 设置窗口（模型 / key / 行为） | key 只显示掩码；「测试连接」是真发一个请求 |
| `ui\workers.py` | 界面用的后台线程 | 界面控件只在主线程碰；属性名不能叫 `_stop` |
| `ui\session_list.py` | 会话列表（搜索 + 自绘行） | 有未读的排最前；群会话带 `［群］` 标记 |
| `ui\chat_view.py` | 聊天气泡（`QListView` + 自绘） | Qt 富文本不支持圆角，所以自己画；非文本不假装有内容 |
| `ui\advice_panel.py` | 建议四块卡片 | 模型没按格式返回时，原文照原样显示 |
| `ui\analysis_panel.py` | 关系体检页（数字卡片 + 六块解读） | 数字在前、解读在后；面板自己不算不调 |
| `ui\review_panel.py` | 复盘浏览 | 只读：不删、不改复盘文件 |
| `ui\icon.py` | 程序图标（代码现画） | 画字之前必须先有 `QGuiApplication`，否则访问冲突 |
| `ui\demo.py` | `--demo` 的假聊天 | 只在演示模式用；界面必须标注"演示数据" |
| `tools\ui_preview.py` | 界面截图（验收/回归） | 用 `windows` 平台 + `WA_DontShowOnScreen`；`offscreen` 插件没字体 |
| `tools\make_icon.py` | 生成 `icon.ico` / `icon.png` | 打包脚本调它；产物不入库 |

## 三条数据流

1. **读**：界面/CLI → `wda.py` → 读取后端 HTTP → 本地解密库（只读，不解密、不外传）。
2. **想**：`brain.build_advice_prompt()` 拼任务书 → `advisor.py` 选通道 →
   直连（`llm.chat_stream()`，SSE 流式，边收边填四块卡片）或兜底（DSH 子进程，一次出全）
   → 文本 → `brain.parse_advice()` 拆成四块 → 界面卡片 + 复盘文件。
3. **写**（全自动档才会触发）：`autopilot.step()` → 读记录判断有没有值得接的新消息 →
   `advisor` 拟稿 → `rules.auto_send_decision()` 放行 → `brake.check()` →
   `pct.switch()` 切会话拿哈希 → `pct.send(expect_hash=…)` → 记账 + 留痕。

## 全自动的一条消息要过几道闸（ADR-0024）

```
收到新消息？ → 最后一条不是自己发的？ → 停手条件没命中？ → 授权有效且没过期？
      → 目标会话匹配？ → 不是群聊？ → 要发的话里没有红线词？ → 制动没按下？
      → 切会话（拿 pane 哈希） → send 带 expect_hash（对话变了就拒发） → 记账 + 留痕
```

上面任何一道不过，**就不发**，并且界面会说清是哪一道。这九道闸与它们对应的判定函数：

| 闸 | 在哪 |
| --- | --- |
| 授权有效 / 目标匹配 / 群聊 / 红线 | `rules.auto_send_decision()` |
| 制动 | `brake.check()`（进键盘前还会再问一次） |
| 上下文（对话有没有变） | 上游 `pct.ps1` 的 `-ExpectHash`，exit 4 = 拒发 |
| 停手条件 | `rules.stop_reason()` |
| 额度与过期 | `rules.AutoGrant.state()` / `sender.consume()` |

## 通道与速度（实测，2026-10-13）

| 做法 | 一次"只回两个字" | 一次 200 字左右 |
| --- | --- | --- |
| DSH 子进程，新建会话 | 2.62 ~ 3.03 秒 | 5.55 秒 |
| DSH 子进程，`--session-id` 复用会话 | 2.63 ~ 2.73 秒 | 未测 |
| 其中：纯进程启动（`--version`） | 0.11 秒 | — |
| 其中：起进程到建好会话 | **1.87 秒** | 1.87 秒 |
| 其中：模型往返 | 0.60 ~ 0.87 秒 | 约 3.6 秒 |
| 直连（本项目的做法） | 去掉那 1.87 秒，且首字即到即显 | 只剩模型时间 |

结论：**慢的不是模型，是每次重新起子进程**。复用会话救不了（只省 0.2~0.3 秒），
`headless` 也不支持流式与常驻——所以要快就只能不走子进程。

### 直连之后还慢？（0.3.1 的教训）

首字延迟几乎只跟**输入长度**和**模型的思考档位**有关：

| 变量 | 实测 |
| --- | --- |
| `reasoning_effort` 走服务端默认（`max`） | 先想 18537 字，首字 **136.7 秒** |
| 显式发 `reasoning_effort: "low"` | 想 482 字，首字 8.4 秒 |
| 再把任务书从 12978 精简到 10223 字符 | 首字 3.0 秒 |
| 两段式：第一段瘦到 3349 字符 | 首字 **1.36 秒** |

两条经验写进代码：**① 一定要显式指定思考档位**（别信服务端的"推荐默认值"）；
**② 首字只跟输入长度有关，所以把"马上要用的那句"和"完整分析"拆成两次请求**。

## 界面的线程模型

- 界面线程只负责画。
- 体检、读会话、读记录、问军师、查记忆库全部丢进 `Worker(QThread)`；
  同一个 `key` 同时在跑的只允许一个（`self._running` 集合），避免重复点击堆线程。
- 退出（关窗、托盘退出、`aboutToQuit`）都走 `MainWindow.shutdown()`：
  停定时器 → 等后台线程 → 注销热键 → 收托盘。

## 失败模式与对策

| 失败 | 症状 | 对策 |
| --- | --- | --- |
| 读取后端没起 | 端口 10392 无响应 | 体检报 `[×]`；界面点「启动读取后端」 |
| 45 天时效到期 | 后端起不来，日志 `Broker code signature validation failed` | 体检报剩余天数；到期前 7 天转 warn |
| DSH 不在 PATH | `dsh` 找不到 | 直接调 `node <bin.js>`，不依赖 PATH |
| 窗口被别的程序压住 | 点击落点校验失败 | 这是上游的保护，不硬点；用热键制动 |
| 上下文过期 | `pct.send` 抛 `StaleSendError` | 重读再拟，绝不重发旧话 |
| 直连不可用（没 key / 欠费 / 断网） | 点了没反应？ | 自动回退 DSH 兜底，状态栏写明"这次是兜底"（ADR-0019） |
| 模型没按格式返回 | 四块里只有【判断】有内容 | 原文照原样显示，不假装拆好了；流式中间态不误报 |
| 群聊也想问军师 | 按钮是灰的 | 这是有意为之（ADR-0020），0.4.0 会给出会话级开关 |
| 进程退出崩 | 退出码 `0xC0000409` | 退出必须 `shutdown()`：停定时器、join 热键线程、等后台任务 |
| exe 找不到数据根 | 打包后另建一份空 `关系档案\` | `project_home()` 先看 `sys.executable` 位置；必要时设 `GOUTOU_HOME` |
| 界面截出来一个字都没有 | `offscreen` 平台字体库为空（实测 0 个） | 截图工具改用 `windows` + `WA_DontShowOnScreen` |
| 画图标时静默崩溃 | 退出码 `0xC0000005` | `QFont` 之前必须先建 `QGuiApplication`，并把引用留到模块级 |

## 为什么不用 Electron / 不读凭据库 / 不重写发送

- **Electron**：本机 Python + PyQt5 已齐备，调 PowerShell 与 SQLite 最省事；Electron 要多装打包器、体积 200 MB 起。
- **不读凭据库**（`<DSH 主目录>\.credentials.yaml`）：那是主会话钥匙，交给一个会自动发消息的程序不合适；子进程路线不需要任何凭据。
- **不重写发送**：键盘注入是上游踩了 19 条坑才稳下来的（窗口生命周期、前台与置顶的区别、落点校验、稳定帧哈希），重写等于把最危险的部分重造一遍。
